# Agents

## Self-reflection

When giving a final response always provide a confidence score (0-100%).
If you can not do something, say so and request user input for further actions.

## Keep it simple

Keep responses and written files like docs, skills, prompts and configs short.
Give direction instead of long lists, so others can read and pick it up quickly.

## Relevant Documentation

When needing/using documentation about programming languages, libraries etc., request up-to-date docs, before answering.
If a specific version is mentioned, use that version, otherwise use the latest version and its standards & best practices.

## File access

When searching for files, text, etc. in the current project, try to prioritize using relative paths from this root.
This is wanted as using external/absolute paths might and will result in more permission requests to the user.
